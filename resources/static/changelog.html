28 февраля 2026 (обновление 4)

🎰 Модуль генерации оружия и брони

  • ✨ Добавлена процедурная генерация оружия и брони:
    • Новый модуль item_generator.py для инкапсулированной генерации предметов
    • Предметы состоят из двух категорий: основа (что это: меч/топор/броня) и материал (из чего: сталь/серебро/мифрил) + свойства (позитивные/негативные)
    • Структура: [Основа], [материал], [свойства] (например, "Меч, сталь" или "Тяжёлая броня, железо")
    • Цена = сумма цен основы + материала + цен свойств (свойства могут иметь отрицательную цену)
    • Все параметры генерации конфигурируются в JSON
  • ⚔️ Типы предметов:
    • Оружие: 7 типов основ (меч, кинжал, топор, булава, копьё, лук, двуручный меч) × 8 материалов (железо, сталь, бронза, серебро, мифрил, магическая сталь, орочья сталь, адамантит)
    • Броня: 7 типов основ (лёгкая, средняя, тяжёлая, пластинчатая, чешуйчатая, кожаная, кольчуга) × 8 материалов (железо, сталь, бронза, кожа, серебро, мифрил, магическая сталь, драконья чешуя)
    • Свойства: Позитивные (острое, зачарованное, укреплённое, гибкое, устойчивое, благословённое, непробиваемое) + Негативные (тяжёлое, тупое, хрупкое, проклятое, несбалансированное, ограничивающая, ржавая, повреждённая, тесная)
  • 🔗 Интеграция с торговцами:
    • Оружейник (⚔️) теперь генерирует мечи вместо выборки из файла
    • Бронник (🛡️) теперь генерирует броню вместо выборки из файла
    • В конфиге торговца вместо resource_file используется generate (например, "generate": "weapon", "subtype": "sword")
    • Другие предметы в инвентаре (стрелы, металл) выбираются как обычно
    • Кэширование ассортимента полностью сохранено
  • 📊 API endpoints для прямой генерации:
    • GET /api/generate/weapon?subtype=sword&count=5 — генерировать 5 мечей
    • GET /api/generate/armor?subtype=heavy&count=3 — генерировать 3 комплекта брони
    • Полезны для тестирования и прямого использования в клиентских приложениях
  • 📈 Структура ответа торговца:
    • Теперь каждый предмет может содержать parts (массив имён частей) и properties (массив имён свойств)
    • Для сгенерированных предметов эти поля заполнены, для обычных = null

  • 📝 Затронутые файлы:
    • resources/item_generator.py — новый модуль генерации
    • resources/jsons/configs/item_generator.json — конфиг типов предметов (основа + материал для каждого типа)
    • resources/jsons/generator/weapon/parts/bases.json — 7 типов оружия
    • resources/jsons/generator/weapon/parts/materials.json — 8 материалов для оружия
    • resources/jsons/generator/weapon/properties/*.json — позитивные и негативные свойства оружия
    • resources/jsons/generator/armor/parts/bases.json — 7 типов брони

Система Торговцев

  • 🔄 Переработана конфигурация торговцев — теперь единая структура для стандартных и именных:

  • ✅ Добавлен механизм приоритизации товаров:
    • Категории группируются по priority (убывание)
    • Товары рандомятся по приоритетам до заполнения всех слотов
    • Применяется новая функция _build_trader_inventory()
  • ✅ Введено кеширование инвентаря торговцев:
    • Каждый торговец генерируется один раз и хранится в памяти
    • Сброс кеша через админку кнопкой 🔄 Сброс кеша

Система Сокровищ
