# Генератор предметов

## Обзор

Генератор предметов — модульная система создания оружия и брони из **частей** (parts) и **свойств** (properties) с взвешенной случайной выборкой. Используется как напрямую через движок `item_generator`, так и внутри `trader_inventory` для генерации инвентаря торговцев.

## Алгоритм генерации

Функция `generate_item(category, subtype)` в `resources/item_generator.py`:

1. **Загрузка конфига** из DataLibrary по слагу `config.item_gen.default`
2. **Выбор частей** — для каждого слота (основа, материал) выбирается ОДИН элемент через `_pick_one()`:
   - Считается суммарный вес вероятностей
   - Случайный порог определяет выбор по распределению весов
   - Цены частей суммируются
3. **Выбор свойств** — для каждой группы свойств выбирается НЕСКОЛЬКО через `_pick_many()`:
   - Случайное количество в диапазоне `count_min` — `count_max`
   - Выбор **без возврата** (выбранный элемент убирается из пула)
   - Цены свойств накапливаются (могут быть отрицательными)
4. **Итоговая цена** = сумма цен частей + сумма цен свойств (минимум 0)
5. **Результат**:
   ```json
   {
     "name": "Часть1, Часть2, Свойство1",
     "price": 280,
     "probability": 100,
     "parts": ["Длинный меч", "Стальной"],
     "properties": ["Острое", "Зачарованное"]
   }
   ```

### Функции рандомизации

- `_pick_one(items)` — одиночный взвешенный выбор
- `_pick_many(items, count)` — множественный выбор без возврата

## Структура конфигурации

**Файл:** `resources/jsons/configs/item_generator.json`

```json
{
  "weapon": {
    "sword": {
      "name": "Меч",
      "parts": [
        {"slot": "base", "name": "Основа", "source": "gen.weapon.parts.bases"},
        {"slot": "material", "name": "Материал", "source": "gen.weapon.parts.materials"}
      ],
      "property_groups": [
        {"name": "Позитивные", "source": "gen.weapon.props.positive", "count_min": 1, "count_max": 2},
        {"name": "Негативные", "source": "gen.weapon.props.negative", "count_min": 0, "count_max": 1}
      ]
    }
  },
  "armor": { ... }
}
```

- Верхний уровень: **категории** (weapon, armor)
- Внутри: **подтипы** (sword, bow, heavy, light и т.д.)
- Каждый подтип: `parts` (слоты для заполнения) + `property_groups` (группы модификаторов)

## Структура JSON-файлов данных

```
resources/jsons/generator/
├── weapon/
│   ├── parts/
│   │   ├── bases.json        — 10 типов оружия (меч, кинжал, топор...)
│   │   └── materials.json    — 8 материалов (железо, сталь, серебро, мифрил...)
│   └── properties/
│       ├── positive.json     — 6 позитивных (острое, сбалансированное, зачарованное...)
│       └── negative.json     — 5 негативных (тяжёлое, тупое, хрупкое, проклятое...)
└── armor/
    ├── parts/
    │   ├── bases.json        — 8 типов брони (кираса, кольчуга, латы...)
    │   └── materials.json    — 8 материалов (железо, сталь, кожа, тёмная сталь...)
    └── properties/
        ├── positive.json     — 6 позитивных (укреплённая, зачарованная, гибкая...)
        └── negative.json     — 6 негативных (тяжёлая, ограничивающая, ржавая...)
```

**Формат каждого файла данных:**
```json
{
  "_config": { "description": "..." },
  "steel": {
    "name": "Стальной",
    "price": 60,
    "probability": 70
  }
}
```

- `name` — отображаемое имя
- `price` — цена (может быть отрицательной для негативных свойств)
- `probability` — вес вероятности (чем выше, тем чаще выпадает)

## Пример генерации

**Меч (weapon → sword):**
- Основа: «Длинный меч» (120 зол.)
- Материал: «Стальной» (60 зол.)
- Позитивные (1-2): «Острое» (50), «Зачарованное» (200)
- Негативные (0-1): «Тяжёлое» (-30)
- **Итого:** цена = 120 + 60 + 50 + 200 - 30 = **400 золотых**

## Движок (Engine)

**Класс:** `ItemGenEngine` в `resources/engines/item_gen.py`

| Поле | Значение |
|------|----------|
| engine_id | `item_generator` |
| name | Генератор предметов |

### Действия (actions)

**`get_types`** — возвращает все категории и подтипы:
```json
{"types": {"weapon": ["sword", "bow", ...], "armor": ["heavy", "light", ...]}}
```

**`generate`** — генерирует предметы:
- Параметры: `category`, `subtype`, `count` (1-100, по умолчанию 1)
- Ответ: `{"items": [...]}`

## API

```
POST /api/games/{game_id}/engines/item_generator/action
Body: {"action": "generate", "payload": {"category": "weapon", "subtype": "sword", "count": 3}}
```

Доступно для членов игры (player+).

## Использование в торговцах

`TraderInventoryEngine` использует генератор для динамического создания инвентаря:

```json
{
  "armor_vendor": {
    "categories": [
      {"priority": 1, "generate": "armor", "subtype": "heavy", "count": 3},
      {"priority": 2, "resource_file": "custom_items", "count": 2}
    ],
    "coefficient": 1.5
  }
}
```

Торговец смешивает сгенерированные и статические предметы, применяя ценовой коэффициент.

## Настройка генератора администратором игры

### Что можно менять

| Что | Где менять | Как влияет |
|-----|-----------|------------|
| Вес (вероятность) предмета | Поле `probability` в каталоге | Чем выше — тем чаще выпадает при генерации |
| Цена предмета | Поле `price` в каталоге | Влияет на итоговую стоимость (может быть отрицательной) |
| Добавить/удалить предмет | Добавить/убрать запись в каталоге | Расширяет или сужает пул генерации |
| Количество свойств | Поля `count_min`/`count_max` в конфиге | Сколько позитивных/негативных свойств получит предмет |
| Новый подтип оружия/брони | Добавить секцию в конфиг генератора | Появится новый вариант в UI генерации |
| Новая группа свойств | Добавить `property_group` в конфиг | Добавит ещё один набор модификаторов |

### Пошаговая инструкция

#### Вариант 1: Изменить данные в существующих каталогах (глобально)

Подходит, если нужно поправить веса/цены/названия для всех игр.

1. Перейти на `/libraries`
2. Найти нужный системный каталог (например, `gen.weapon.parts.bases`)
3. Нажать **«Копировать»** — создастся пользовательская копия с новым слагом
4. Отредактировать копию:
   - Изменить `probability` у записей (вес выпадения)
   - Изменить `price` (цена)
   - Добавить новые записи или удалить ненужные
5. Сохранить

#### Вариант 2: Создать свой движок с кастомными данными (для конкретной игры)

Подходит, если в разных играх нужны разные наборы предметов.

1. **Создать кастомные каталоги:**
   - `/libraries` → «+ Создать» → тип `item_catalog`
   - Заполнить своими предметами (name, price, probability)
   - Запомнить слаг (например, `my.dark.weapons.bases`)

2. **Создать кастомный конфиг генератора:**
   - `/libraries` → скопировать `config.item_gen.default`
   - В копии заменить слаги `source` на свои каталоги:
     ```json
     {"slot": "base", "source": "my.dark.weapons.bases"}
     ```
   - Настроить `count_min`/`count_max` для групп свойств
   - Сохранить (например, как `config.item_gen.dark_world`)

3. **Создать пользовательский движок:**
   - `/my-engines` → «Копировать системный» → «Генератор предметов»
   - В настройках указать свой конфиг: `config_file` → `config.item_gen.dark_world`
   - Сохранить

4. **Подключить к игре:**
   - `/games` → выбрать игру → вкладка «Движки»
   - Нажать «Мои движки» → выбрать созданный движок
   - Теперь в этой игре генератор использует кастомные данные

5. **Проверить:**
   - `/my-engines` → открыть движок → вкладка «Симулятор»
   - Выполнить действие `generate` с параметрами `{category, subtype, count}`
   - Убедиться, что результат соответствует ожиданиям

### Примеры типичных задач

**Сделать мифрил редким:**
В каталоге `gen.weapon.parts.materials` уменьшить `probability` у мифрила (например, с 20 до 5).

**Добавить новый тип оружия «Посох»:**
1. В каталоге `gen.weapon.parts.bases` добавить запись:
   ```json
   "staff": {"name": "Посох", "price": 80, "probability": 40}
   ```
2. В конфиге `config.item_gen.default` добавить подтип:
   ```json
   "staff": {
     "name": "Посох",
     "parts": [
       {"slot": "base", "source": "gen.weapon.parts.bases"},
       {"slot": "material", "source": "gen.weapon.parts.materials"}
     ],
     "property_groups": [
       {"name": "Позитивные", "source": "gen.weapon.props.positive", "count_min": 1, "count_max": 3},
       {"name": "Негативные", "source": "gen.weapon.props.negative", "count_min": 0, "count_max": 1}
     ]
   }
   ```

**Убрать негативные свойства совсем:**
В конфиге генератора удалить группу «Негативные» из `property_groups` нужного подтипа.

### Ограничения

- Нельзя изменить сам алгоритм генерации (взвешенная выборка) без правки Python-кода
- Нельзя изменить структуру слотов частей (всегда выбирается ровно 1 элемент на слот)
- Системные каталоги (owner_id=NULL) доступны только для чтения — нужно копировать
