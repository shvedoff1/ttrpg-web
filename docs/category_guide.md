# Гайд: настройка движков через категории + привязки ресурсов

Этот гайд описывает как создать и настроить движки, используя систему категорий + привязки ресурсов (bindings).

---

## Общий принцип

1. Создать **категорию** (название + иконка)
2. Добавить в категорию **движки** — каждый движок = 1 примитив или 1 системный движок
3. **Привязать ресурсы** к движку через теги (новая система) или slug-конфиг (legacy)
4. Настроить контексты/фильтры через визуальный UI
5. Привязать категорию к игре
6. В игре категория отображается как **табы**, каждый таб — один движок

### Два режима конфигурации

- **Bindings (новый)** — движок привязывает ресурсы через `engine_resource_bindings` с тегами. Контексты, фильтры, пресеты хранятся в `config` движка. Настройка через визуальный редактор привязок.
- **Legacy (slug-based)** — движок ссылается на slug-и DataLibrary. Настройка через JSON-конфиг.

## 1. Профессии

Каждая профессия — отдельный движок в категории.

### Категория: «⚔ Профессии»

#### Травы (context_roll + bindings)

1. Создать движок, выбрать примитив `context_roll`
2. Привязать ресурсы: теги `["alchemy", "herb"]`, роль `source`
3. Настроить контексты (локации) в визуальном редакторе:
   - Луговые: переопределения вероятностей для трав, растущих на лугу
   - Лесные: переопределения вероятностей для лесных трав
   - и т.д.

| Поле | Значение |
|------|----------|
| Примитив | `context_roll` |
| Привязка | tags: `["alchemy", "herb"]`, role: `source` |
| Config | `contexts: {meadow: {name, item_key: prob, ...}, forest: {...}, ...}` |

#### Руды, Следы — аналогично с соответствующими тегами

#### Воровство (filtered_roll + bindings)

1. Примитив `filtered_roll`
2. Привязки: несколько наборов ресурсов (еда, инструменты, зелья и т.д.)
3. Фильтры по районам в визуальном редакторе:
   - Бедный: убрать 75% редких
   - Обычный: убрать 20% редких
   - Богатый: убрать 20% дешёвых
   - Магический: убрать 20% дешёвых

#### Тайник (loot_bundle + bindings)

1. Примитив `loot_bundle`
2. Привязки: несколько наборов ресурсов
3. Пресеты выдачи по районам:
   - Бедный: 0–50 золота, 1–3 предмета
   - Обычный: 50–150 золота, 2–4 предмета
   - Богатый: 150–500 золота, 3–5 предметов

## 3. Генератор предметов (item_generator)

### С привязками ресурсов (новый способ)

1. Примитив `item_generator`
2. Привязки по ролям:
   - `parts:base` — теги `["generator", "weapon", "part", "base"]`
   - `parts:material` — теги `["generator", "weapon", "part", "material"]`
   - `props:positive` — теги `["generator", "weapon", "property", "positive"]`
   - `props:negative` — теги `["generator", "weapon", "property", "negative"]`
3. Config: `templates` с настройками каждого подтипа (количество свойств и т.д.)

### Как системный движок (legacy)

| # | Название | Тип | type_id | Конфиг |
|---|----------|-----|---------|--------|
| 1 | Генератор | system | `item_generator` | `config_file`: slug конфига |

---

## 4. Торговцы (pool_sample + bindings)

### Через привязки

1. Примитив `pool_sample`
2. Привязки с приоритетами:
   - priority 2: теги `["craft", "weapon"]`, count: 5
   - priority 1: теги `["hunt", "arrow"]`, count: 3
3. Config: `objects_count`, `coefficient`

### Как системный движок (legacy)

| # | Название | Тип | type_id |
|---|----------|-----|---------|
| 1 | Торговцы | system | `trader_inventory` |

---

## 5. Мотивации (weighted_sample + bindings)

1. Примитив `weighted_sample`
2. Привязка: теги `["motivation"]`, роль `source`
3. Config: `count: 3`

---

## 6. Сокровища (cascade_roll + bindings)

1. Примитив `cascade_roll`
2. Несколько привязок, каждая = категория сокровищ:
   - Зелья: теги `["alchemy", "potion"]`, category_weight: 40, label: "Зелья", icon: "🧪"
   - Оружие: теги `["craft", "weapon"]`, category_weight: 30, label: "Оружие", icon: "⚔"
   - Свитки: теги `["misc", "scroll"]`, category_weight: 30, label: "Свитки", icon: "📜"

## Комбинированные категории

Можно комбинировать движки из разных примитивов в одну категорию:

### Категория: «🎲 Всё для мастера»

| # | Название | Примитив | Ресурсы |
|---|----------|----------|---------|
| 1 | Сокровища | `cascade_roll` | Зелья, Оружие, Свитки (каждое — отдельная привязка) |
| 2 | Мотивация NPC | `weighted_sample` | tags: `["motivation"]`, count: 3 |
| 3 | Сундуки | system `chest_game` | Конфиг через slug |
| 4 | Генератор лута | `item_generator` | Части и свойства через привязки |

Все 4 движка будут отображаться как табы в одном виджете.

---

## Справочник примитивов

| primitive_id | Название | Действия | Роли привязок | Описание |
|-------------|----------|----------|---------------|----------|
| `weighted_roll` | Взвешенный бросок | `roll` | 1× `source` | Один предмет из взвешенного списка |
| `context_roll` | Контекстный бросок | `roll`, `list_contexts` | 1× `source` | Бросок с модификаторами по локации |
| `filtered_roll` | Фильтрованный бросок | `roll`, `list_contexts` | N× `source` | Бросок с исключением редких/обычных |
| `loot_bundle` | Набор лута | `roll`, `list_contexts` | N× `source` | Золото + N случайных предметов |
| `cascade_roll` | Каскадный бросок | `roll` | N× `source` (каждая = категория) | Категория → предмет |
| `weighted_sample` | Выборка | `sample` | 1× `source` | N предметов без повторений |
| `pool_sample` | Пул | `build` | N× `source` с priority+count | Инвентарь из приоритетных групп |
| `item_generator` | Генератор | `generate`, `get_types` | `parts:base`, `parts:material`, `props:positive`, `props:negative` | Процедурная генерация оружия/брони |

## Порядок действий

1. Зайти в **Категории** (навигация)
2. Нажать **+ Создать категорию**
3. Указать название, иконку, описание
4. Добавить движки: выбрать примитив
5. **Привязать ресурсы**: выбрать теги, указать роль, при необходимости настроить переопределения вероятностей
6. **Настроить контексты/фильтры/пресеты** через визуальный редактор (для context_roll, filtered_roll, loot_bundle)
7. Протестировать через **Симулятор** в редакторе движка
8. Зайти в **Игры** → выбрать игру → вкладка **Движки**
9. В секции **Категории** нажать **+ Добавить**
10. Проверить что категория отображается на странице игры
