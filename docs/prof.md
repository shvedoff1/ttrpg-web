# Движок профессий (Profession Roll)

## Обзор

Движок профессий — система взвешенного ролла по профессиям и локациям. Поддерживает два режима: **сбор ресурсов** (травы, руды, следы) по локациям и **воровство** (карманная кража / поиск схрона) по районам.

## Архитектура

**Класс:** `ProfessionRollEngine` в `resources/engines/profession_roll.py`

| Поле | Значение |
|------|----------|
| engine_id | `profession_roll` |
| name | Профессии |
| description | Взвешенный ролл по локации/профессии (травы, руды, следы, воровство) |

## Режимы работы

### 1. Сбор ресурсов (location-based roll)

Профессии: **Травы**, **Руды**, **Следы**.

Каждая профессия определена парой слагов: `(каталог_предметов, конфиг_локаций)`.

```python
_DEFAULT_SOURCES = {
    "Травы":  ("items.alchemy.herbs",   "config.profession_roll.herbs"),
    "Руды":   ("items.craft.ores",      "config.profession_roll.ores"),
    "Следы":  ("items.hunt.trophies",   "config.profession_roll.trophies"),
}
```

**Алгоритм ролла** (функция `roll_with_locations()` из `_helpers.py`):

1. Загружается **каталог предметов** — словарь `{key: {name, price, probability}}`
2. Загружается **конфиг локаций** — для выбранной локации берётся `overrides` — словарь `{item_key: weight}`
3. Для каждого ключа из `overrides` ищется предмет в каталоге, собирается пул `[{name, price, w}]`
4. Выполняется **взвешенный случайный выбор** — чем выше `w`, тем вероятнее выпадение
5. Результат: `{name, price}`

### 2. Карманная кража (steal)

**Алгоритм** (функция `_roll_steal()`):

1. Загружаются все предметы из `categories` конфига воровства (еда, инструменты, зелья, свитки и т.д.)
2. Предметы **сортируются** по `probability` (от дешёвых к редким)
3. Применяется **фильтр по району**:
   - `exclude_rarest` — отсекает N% самых редких предметов (бедный район: 75%, обычный: 20%)
   - `exclude_common` — отсекает N% самых частых предметов (богатый/магия: 20%)
4. Из оставшегося пула — взвешенный выбор одного предмета
5. Результат: `{name}`

### 3. Поиск схрона (cache)

**Алгоритм** (функция `_roll_cache()`):

1. По ключу района определяются диапазоны золота и количества предметов
2. Генерируется случайное количество золота в диапазоне `[gold_min, gold_max]`
3. Генерируется случайное количество предметов в диапазоне `[items_min, items_max]`
4. Из каталогов района выбирается указанное количество предметов (взвешенный выбор **с возвратом**)
5. Результат: `{name, gold, items: [...]}`

| Район | Золото | Предметов |
|-------|--------|-----------|
| Бедный | 0–50 | 1–3 |
| Обычный | 50–150 | 2–4 |
| Богатый | 150–500 | 3–5 |
| Обитель магии | 100–400 | 2–4 |

## Действия (actions)

### `get_professions`
Возвращает список профессий из `sources` + «Воровство» (если включена хотя бы одна из опций `enable_steal` / `enable_cache`).
```json
{"professions": ["Травы", "Руды", "Следы", "Воровство"]}
```

### `get_locations` — `{profession}`
Для ресурсных профессий — список локаций:
```json
{"locations": [{"key": "type1", "name": "Луговые"}, ...]}
```

Для «Воровство» — каскадный выбор:
1. Без `param1` → возвращает режимы: `{"modes": [{"key": "steal", "name": "Карманная кража"}, {"key": "cache", "name": "Поиск схрона"}]}`
2. Если включён только один режим — пропускает шаг выбора, сразу возвращает районы с полем `_mode`
3. С `param1` → возвращает районы: `{"locations": [{"key": "poor", "name": "Бедный район"}, ...]}`

### `roll` — `{profession, location}`
Ролл ресурса по профессии и локации. Результат: `{name, price}`.

### `roll_steal` — `{district}`
Ролл карманной кражи. Результат: `{name}`.

### `roll_cache` — `{district}`
Ролл схрона. Результат: `{name, gold, items: [...]}`.

## Структура конфигурации

### Конфиг локаций (травы/руды/следы)

```json
{
  "type1": {
    "name": "Луговые",
    "overrides": {
      "herb_0": 5,
      "herb_1": 20,
      "herb_23": 99
    }
  }
}
```

- Ключи `overrides` — ID предметов из каталога
- Значения — вес вероятности (чем выше, тем чаще выпадает)
- В каждой локации свой набор доступных предметов с уникальными весами

### Конфиг воровства (steal_config)

```json
{
  "categories": ["items.food.food", "items.misc.tools", "..."],
  "district_filter": {
    "poor":   {"filter": "exclude_rarest", "percent": 75},
    "normal": {"filter": "exclude_rarest", "percent": 20},
    "rich":   {"filter": "exclude_common", "percent": 20},
    "magic":  {"filter": "exclude_common", "percent": 20}
  }
}
```

### Конфиг тайников (cache_config)

```json
{
  "poor": {
    "name": "Схрон · Бедный район",
    "gold_min": 0, "gold_max": 50,
    "items_min": 1, "items_max": 3,
    "categories": ["items.food.food", "..."]
  }
}
```

## Настройки движка (config schema)

| Ключ | Тип | Описание |
|------|-----|----------|
| `sources` | key_value_map | Профессии: название → `[каталог_предметов, конфиг_локаций]` |
| `enable_steal` | boolean | Включить карманную кражу (по умолчанию `true`) |
| `enable_cache` | boolean | Включить поиск схрона (по умолчанию `true`) |
| `steal_config_file` | slug_picker | Слаг конфига воровства |
| `cache_config_file` | slug_picker | Слаг конфига тайников |
| `roll_label` | text | Текст кнопки (по умолчанию «Бросить») |
| `show_price` | boolean | Показывать ли цену в результате |

## Слаги DataLibrary

| Слаг | Файл | Описание |
|------|------|----------|
| `config.profession_roll.herbs` | configs/herb_locations.json | Веса трав по типам местности |
| `config.profession_roll.ores` | configs/ore_locations.json | Веса руд по типам местности |
| `config.profession_roll.trophies` | configs/trophy_locations.json | Веса трофеев по типам местности |
| `config.profession_roll.steal` | configs/steal_config.json | Параметры воровства по районам |
| `config.profession_roll.cache` | configs/cache_config.json | Параметры тайников по районам |

## Фронтенд

**Файл:** `resources/static/js/engines/profession_roll.js`

Поток UI:
1. Загрузка списка профессий через `get_professions`
2. Сетка выбора профессии (Травы / Руды / Следы / Воровство)
3. **Для ресурсов:** сетка выбора локации → кнопка «Бросить» → результат
4. **Для воровства:** выбор типа (Кража / Схрон) → выбор района → кнопка «Бросить» → результат
5. Публикация результата в журнал игры с иконкой ⚔

## Настройка администратором

### Что можно менять

| Что | Где менять | Как влияет |
|-----|-----------|------------|
| Веса предметов в локации | `overrides` в конфиге локаций | Чем выше вес, тем чаще выпадает |
| Набор предметов в локации | Добавить/удалить ключ в `overrides` | Расширяет/сужает пул выпадения |
| Добавить новую локацию | Новая секция в конфиге локаций | Появится в UI выбора |
| Фильтр воровства по району | `district_filter` в steal_config | Какие предметы доступны в районе |
| Диапазоны золота/предметов схрона | Поля `gold_min/max`, `items_min/max` | Сколько золота и предметов в схроне |
| Добавить новую профессию | Добавить запись в `sources` конфига движка | Появится новая профессия в UI |
| Показывать цену | Настройка `show_price` движка | Показывает/скрывает цену в результате |

### Пошаговая инструкция: добавить профессию

1. **Создать каталог предметов** — `/libraries` → «+ Создать» → тип `item_catalog`, заполнить `{name, price, probability}`
2. **Создать конфиг локаций** — `/libraries` → «+ Создать» → тип `engine_config`, заполнить локации с `overrides`
3. **Создать пользовательский движок** — `/my-engines` → «Копировать системный» → «Профессии»
4. **В настройках `sources`** добавить новую профессию с парой слагов `[каталог, конфиг_локаций]`
5. **Подключить к игре** — `/games` → выбрать игру → вкладка «Движки» → выбрать созданный движок
