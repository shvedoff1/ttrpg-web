# Движок профессий (Profession Roll)

## Обзор

Движок профессий — система взвешенного ролла по профессиям и локациям. Поддерживает два режима: **сбор ресурсов** (травы, руды, следы) по локациям и **воровство** (карманная кража / поиск схрона) по районам.

## Архитектура

### Legacy (системный движок)

**Класс:** `ProfessionRollEngine` в `resources/engines/profession_roll.py`

Внутренняя декомпозиция на примитивы:

| Действие | Примитив | Файл |
|----------|----------|------|
| `roll` | `ContextRollPrimitive` | `engines/primitives/context_roll.py` |
| `roll_steal` | `FilteredRollPrimitive` | `engines/primitives/filtered_roll.py` |
| `roll_cache` | `LootBundlePrimitive` | `engines/primitives/loot_bundle.py` |
| `get_professions`, `get_locations` | Orchestration logic в движке | — |

### Новая система (через привязки ресурсов)

Каждая профессия — отдельный движок в категории. Ресурсы привязываются через `engine_resource_bindings` с тегами.

| Профессия | Примитив | Привязка (теги, роль) | Engine config |
|-----------|----------|-----------------------|---------------|
| Травы | `context_roll` | `["alchemy", "herb"]`, role: `source` | `contexts: {meadow: {name, overrides}, ...}` |
| Руды | `context_roll` | `["craft", "ore"]`, role: `source` | `contexts: {mountain: {name, overrides}, ...}` |
| Следы | `context_roll` | `["hunt", "trophy"]`, role: `source` | `contexts: {forest: {name, overrides}, ...}` |
| Воровство | `filtered_roll` | N× `source` (еда, инстр., зелья) | `filters: {poor: {...}, rich: {...}}` |
| Тайник | `loot_bundle` | N× `source` | `districts: {poor: {gold_min, gold_max, ...}}` |

## Режимы работы

### 1. Сбор ресурсов (context_roll)

**Через bindings:**
1. Загружаются `resource_items` по тегам привязки
2. Из `config.contexts[location]` берутся переопределения вероятностей (flat dict `{item_key: prob}`)
3. Базовая вероятность из `resource_items.probability`, поверх — override
4. Взвешенный случайный выбор
5. Результат: `{name, price}`

**Через legacy slug:**
1. Загружается каталог предметов по slug
2. Загружается конфиг локаций по slug
3. `roll_with_locations(items, location)` — выбор по `overrides`

### 2. Карманная кража (filtered_roll)

1. Загружаются предметы из привязанных наборов ресурсов
2. Сортируются по весу (от дешёвых к редким)
3. Применяется фильтр по району из `config.filters`:
   - `exclude_rarest` — отсекает N% самых редких
   - `exclude_common` — отсекает N% самых частых
4. Взвешенный выбор одного предмета
5. Результат: `{name}`

### 3. Поиск схрона (loot_bundle)

1. По ключу района из `config.districts` определяются диапазоны
2. Случайное золото `[gold_min, gold_max]`
3. Случайное количество предметов `[items_min, items_max]`
4. Взвешенный выбор предметов из привязанных наборов
5. Результат: `{name, gold, items: [...]}`

| Район | Золото | Предметов |
|-------|--------|-----------|
| Бедный | 0–50 | 1–3 |
| Обычный | 50–150 | 2–4 |
| Богатый | 150–500 | 3–5 |

## Действия (actions)

### `roll` / `list_contexts`
Основные действия для `context_roll`, `filtered_roll`, `loot_bundle`.

`list_contexts` — возвращает список доступных контекстов (локации, районы).

`roll` — выполняет бросок с указанным контекстом.

## Настройка администратором

### Через визуальный редактор привязок (новый способ)

1. Создать категорию «Профессии»
2. Для каждой профессии добавить движок с примитивом `context_roll`
3. Привязать ресурсы через теги
4. Настроить контексты (локации) через визуальный UI:
   - Добавить локацию, указать название
   - В таблице предметов настроить переопределения вероятностей
5. Для воровства — примитив `filtered_roll`, настроить фильтры через UI
6. Для тайника — примитив `loot_bundle`, настроить пресеты через UI

### Что можно менять

| Что | Где | Как влияет |
|-----|-----|------------|
| Вероятности предметов в локации | Переопределения в контексте | Чем выше вероятность, тем чаще выпадает |
| Набор предметов в локации | Переопределение = 0 или удалить | Сужает пул выпадения |
| Добавить новую локацию | Кнопка «+ Добавить контекст» | Появится в UI выбора |
| Фильтр воровства по району | Настройки фильтра (правило + процент) | Какие предметы доступны |
| Диапазоны золота/предметов | Поля min/max в пресете района | Сколько золота и предметов |
