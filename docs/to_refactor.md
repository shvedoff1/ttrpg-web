## Логика, которую нужно перенести на бэкенд

### Дедупликация ресурсов
- **Где:** `bindings-editor.js:473-488`
- **Что:** фронт убирает дубли по `key` при каждой загрузке
- **Действие:** `GET /api/resources` должен отдавать уже уникальные записи

### Валидация (отсутствует на сервере)
| Поле | Проблема |
|------|----------|
| Формат тегов | Принимается любая строка |
| Приоритет/count биндинга | Нет проверки диапазона |
| Вес категории (слайдер 0-10) | Не проверяется на POST/PATCH |
| Имя контекста | Пустые строки допускаются |
| Override-значения | Нет ограничений |
- **Действие:** добавить Pydantic-валидаторы в схемы `BindingCreate`/`BindingUpdate` в `resources/routers/bindings.py`

## Проблемы качества

### Нет debounce на _refreshCount()
- **Где:** `bindings-editor.js:437`
- **Что:** каждое изменение тега = API-запрос без задержки
- **Действие:** добавить debounce 300мс

### Ошибки глотаются молча
- **Пример:** `catch { this._allTags = [] }` — пользователь видит пустой dropdown без объяснения
- **Действие:** показывать toast/alert при ошибках API
